# Systems Integration: Core Concepts and Fundamentals

**Date:** 2026-07-26

| Cue / Keywords | Notes |
| :--- | :--- |
| **System Integration** | Process of bringing different systems together into one unified, interoperable system that facilitates communication across the network. Poor integration is called "Spaghetti Integration". |
| **Enterprise Integration** | Strategic approach achieving interoperability between IT applications (internal/external). Business-driven, involves multiple stakeholders, strategic view rather than localized. |
| **Business Problems Solved** | - **Information Aggregation:** Single view of multiple sources.<br>- **Single point of entry:** Reduced manual/duplicate data entry.<br>- **Process inefficiency:** Reduced effort/time.<br>- **Web channel & Supplier integration:** External access and optimized supply chain. |
| **Integration Methods** | - **Horizontal Integration (ESB):** Subsystem acts as interface between all others.<br>- **Vertical Integration:** Creation of silos.<br>- **Star Integration:** Point-to-point connections.<br>- **Common data format:** Application-independent format/transformation service. |
| **Integration Types** | - **EAI (Enterprise Application Integration):** Internal workflows.<br>- **DI (Data Integration):** Consolidating raw data for analytics.<br>- **EDI (Electronic Data Interchange):** Secure standardized document exchange between external partners. |
| **Implementation Steps** | 1. Requirements Gathering<br>2. Data Analysis<br>3. Design Architecture<br>4. Design Systems integration<br>5. System Implementation |
| **Assessment Needs** | Necessary when there are many isolated systems, duplicate data entries, inconsistent data, difficult information extraction, batch uploads, or need for real-time information collation. |

---

### Summary
Systems integration combines isolated sub-systems into a unified, interoperable whole, primarily to resolve business inefficiencies like data duplication and disjointed workflows. Unlike basic integration, Enterprise Integration is a strategic, business-driven approach. Implementation typically involves standardized phases, relying on methods like Horizontal (ESB), Vertical, or Star integration, and categories like EAI, DI, and EDI depending on the specific integration scope.
