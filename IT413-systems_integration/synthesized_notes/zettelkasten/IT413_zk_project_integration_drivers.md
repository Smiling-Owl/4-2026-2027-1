# Project Drivers Define Specific Integration Outcomes

**Tags:** #systems_integration #project_drivers #business_capabilities

## Note
Project drivers are concrete capabilities or technical outcomes that an integration initiative is expected to deliver:

- **E-business:** Connect legacy business functions to web systems.
- **E-government:** Enable interagency workflows and data exchange.
- **Business intelligence:** Combine sources for pattern and trend analysis.
- **Customer expectations:** Deliver immediate, real-time services and information.
- **Customer relationship management:** Connect customer databases, call centers, and web support.
- **Knowledge management:** Manage and share enterprise knowledge assets.
- **Customer self-service:** Let customers perform staff-assisted services themselves.
- **IT system consolidation:** Move services and applications onto fewer systems.
- **Supply chain management:** Exchange real-time buyer and supplier information.
- **ERP expansion:** Connect a core ERP platform to specialized systems.
