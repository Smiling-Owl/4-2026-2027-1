# System Integration Definition

**Tags:** #systems_integration #definition #architecture

## Note
System integration is the process of bringing together interdependent systems into one unified system to facilitate communication across the network. When done poorly or in an ad-hoc manner, it is referred to as "Spaghetti Integration." It addresses common business problems such as information aggregation, process inefficiency, and duplicate data entry.
