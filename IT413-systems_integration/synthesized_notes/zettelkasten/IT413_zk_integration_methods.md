# Systems Integration Methods

**Tags:** #systems_integration #methods #architecture_patterns

## Note
There are several core methods used to physically and logically connect systems:
- **Horizontal Integration:** Uses an Enterprise Service Bus (ESB) as a central interface subsystem.
- **Vertical Integration:** Creates depositories or silos.
- **Star Integration:** Connects sub-systems via point-to-point connections.
- **Common Data Format:** Utilizes an application-independent format or transformation service.
