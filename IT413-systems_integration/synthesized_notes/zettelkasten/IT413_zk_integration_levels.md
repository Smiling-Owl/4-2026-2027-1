# Five Levels of Integration

**Tags:** #systems_integration #levels #architecture

## Note
Integration can be categorized into five levels:
- **Presentation integration:** Combines information or interface elements from separate applications in a single view (e.g., a portal); may rely on screen scraping when a legacy application lacks an API.
- **Data integration:** Connects systems through their data via extraction, transformation, consolidation, replication, and synchronization among databases, files, and warehouses.
- **Application integration:** Connects systems through their functions; one application exposes an operation via an API, and another invokes it during an operation.
- **Service integration:** Presents application capabilities as reusable services with defined contracts, emphasizing reuse, standard access, and loose coupling.
- **Process integration:** Coordinates a complete business workflow across applications, services, departments, and partner organizations; the broadest level.
