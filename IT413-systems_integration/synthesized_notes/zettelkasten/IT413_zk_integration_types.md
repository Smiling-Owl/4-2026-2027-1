# Integration Types (EAI, DI, EDI)

**Tags:** #systems_integration #integration_types #EAI #EDI

## Note
Primary categories of systems integration include:
- **Enterprise Application Integration (EAI):** Connects internal workflows and applications for real-time actions.
- **Data Integration (DI):** Consolidates raw data from multiple databases into a single repository (analytics/reporting).
- **Electronic Data Interchange (EDI) Integration:** Facilitates secure, computer-to-computer exchange of standardized documents between external partners.
