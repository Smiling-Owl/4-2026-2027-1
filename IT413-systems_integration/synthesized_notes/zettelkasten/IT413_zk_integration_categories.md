# Integration Categories (Web, EAI, B2B)

**Tags:** #systems_integration #integration_types #web #eai #b2b

## Note
There are three categories of integration, distinguished mainly by scope:
- **Web Integration:** Connects a website or web application with other applications, services, or data sources through web standards (HTTP APIs or web services), allowing a web channel to access or expose back-end functions.
- **Enterprise Application Integration (EAI):** Connects applications within the same organization via APIs, adapters, messaging, middleware, or an integration platform, solving information silos.
- **Business-to-Business (B2B):** Extends integration beyond one organization, connecting the systems and processes of independent trading partners through EDI, APIs, or standards like ebXML.

These categories are distinct but not mutually exclusive — a B2B transaction may enter through a web API and pass through an EAI platform before reaching an internal system.
