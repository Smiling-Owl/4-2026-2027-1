# Missing Values Require Context-Sensitive Cleaning

**Tags:** #DataMining #DataCleaning #MissingData

## Note
Missing data can be handled by deleting a record, entering a value manually, assigning a global constant such as `unknown`, or substituting an attribute mean.

No method is universally best. Deletion is more reasonable when a record lacks several attributes, manual filling is impractical at scale, constants create an explicit missing category, and mean substitution is simple but reduces natural variation.
