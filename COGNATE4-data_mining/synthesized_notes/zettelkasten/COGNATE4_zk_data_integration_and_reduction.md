# Integration and Reduction Change Dataset Scope

**Tags:** #DataMining #DataIntegration #DataReduction

## Note
Data integration combines information from multiple databases, data cubes, or files into a unified dataset. Data reduction decreases the dataset's volume while aiming to preserve the same or similar analytical results.

Integration broadens the available evidence; reduction makes the resulting dataset cheaper and faster to analyze.
