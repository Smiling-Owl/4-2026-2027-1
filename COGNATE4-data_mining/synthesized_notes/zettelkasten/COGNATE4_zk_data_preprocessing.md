# Data Preprocessing Makes Raw Data Usable

**Tags:** #DataMining #DataPreprocessing #DataQuality

## Note
Data preprocessing transforms raw data into a useful and efficient format before analysis. It is necessary because source data may be incomplete, noisy, or inconsistent.

Four major techniques support this goal:

- **Cleaning:** Correct quality problems.
- **Integration:** Combine multiple sources.
- **Transformation:** Change the representation or scale.
- **Reduction:** Decrease volume while preserving similar analytical results.
