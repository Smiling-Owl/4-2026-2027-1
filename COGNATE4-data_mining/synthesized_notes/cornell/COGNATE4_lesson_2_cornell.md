# Cornell Notes: CRISP-DM Framework

| Cue / Keywords | Notes |
| :--- | :--- |
| **CRISP-DM** | - Cross Industry Standard Process for Data Mining.<br>- **Definition:** Base methodology/process model for data science projects.<br>- **Purpose:** Describes project phases, tasks, and their relationships. |
| **Phase 1 & 2** | - **1. Business Understanding:** Identifies objectives/scope; defines the core problem.<br>- **2. Data Understanding:** Gathering relevant data based on business needs from multiple sources. |
| **Phase 3 & 4** | - **3. Data Preparation:** Building final dataset for modeling; identifying required dimensions/variables.<br>- **4. Modelling:** Applying analytical/algorithmic techniques (e.g., clustering, classification); analysts select approaches. |
| **Phase 5 & 6** | - **5. Evaluation:** Validating model accuracy and business fit; ensuring project alignment with initial question.<br>- **6. Deployment:** Utilizing model results for business value; integrating outputs into systems or stakeholder reports. |

## Summary
CRISP-DM (Cross Industry Standard Process for Data Mining) is the foundational methodology for data science projects. It consists of a 6-step process: Business Understanding, Data Understanding, Data Preparation, Modelling, Evaluation, and Deployment. This framework ensures that data mining efforts are aligned with business objectives from conception to implementation.
