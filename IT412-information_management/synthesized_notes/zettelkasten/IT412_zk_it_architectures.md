# Common IT Architectures

**Tags:** #information_management #it #architecture

## Note
- **Centralized Architecture:** A large central computer system runs all applications and stores all data; all functionality is located in one place to make it easier to manage.
- **Decentralized Architecture:** Computing power is spread out among a number of devices in different locations, typically chosen to modularize and address concerns about scalability.
- **Service-Oriented (Cloud-based) Architecture:** Software is broken down into services, orchestrated and connected to each other in order to be agile, reusable, and facilitate rapid app design.
- **Software-Defined Architecture:** Infrastructure can be reconfigured autonomously based on rules to flexibly manage resources.
