# IT Architecture vs. IT Infrastructure

**Tags:** #information_management #it #architecture #infrastructure

## Note
IT Architecture is the blueprint for translating business strategy into a system plan; it defines what needs to be built. IT Infrastructure is everything that supports the flow and processing of information, including the hardware, software, data, and network components that are chosen and assembled; it defines what is built.

The process runs from Strategy (business goals and vision) to Architecture (blueprint and plans) to Infrastructure (actual hardware, software, network, data). Functional specifications describe what each component must do, while technical specifications detail how to implement the system; components are then combined into a coherent, viable infrastructure.
