# Poll and Select Let a Primary Coordinate Secondary Stations

**Tags:** #data_communications #line_discipline #protocols

## Note
In a primary/secondary link arrangement, polling invites a secondary to send data to the primary. Selecting addresses a secondary when the primary has data to send. The distinction follows the direction and purpose of the exchange.
