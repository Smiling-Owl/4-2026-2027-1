# Sliding Windows Keep a Link Busier Than Stop-and-Wait

**Tags:** #data_communications #flow_control #protocols

## Note
Flow control limits in-flight data to what a receiver can process and buffer. Stop-and-wait allows one unacknowledged frame at a time, making it simple but often idle during a round trip. Sliding windows allow multiple numbered frames in transit and advance as acknowledgments arrive.
