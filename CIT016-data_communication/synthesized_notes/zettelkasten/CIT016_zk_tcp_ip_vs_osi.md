# TCP/IP vs OSI Model Comparison

**Tags:** #networking #models #osi #tcp_ip

## Note
The TCP/IP and OSI models have fundamental architectural differences:
- **Layers:** TCP/IP has 4 layers; OSI has 7. TCP/IP merges OSI's Application, Presentation, and Session layers into one Application layer.
- **Approach:** TCP/IP is a horizontal, connectionless approach; OSI is vertical.
- **Network Layer:** TCP/IP's network layer provides strictly connectionless services (IP); OSI provides both connectionless and connection-oriented services.
- **Delivery:** TCP/IP does not guarantee packet delivery by default; OSI features guaranteed delivery.
- **Flexibility:** Protocols in the OSI model are easier to replace than those in the TCP/IP stack.
