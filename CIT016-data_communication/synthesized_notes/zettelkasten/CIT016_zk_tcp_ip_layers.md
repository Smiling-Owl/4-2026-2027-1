# The 4 Layers of TCP/IP Stack

**Tags:** #networking #tcp_ip #architecture

## Note
The TCP/IP model simplifies network communication into 4 distinct layers:
1. **Application Layer:** Provides network services directly to end-user applications (HTTP, FTP, SMTP).
2. **Transport Layer (TCP/UDP):** Manages end-to-end communication, data integrity, and flow control.
3. **Internet Layer (IP):** Handles logical transmission and packet routing using IP addresses.
4. **Network Access Layer:** Responsible for error prevention and physical framing on the local network.
