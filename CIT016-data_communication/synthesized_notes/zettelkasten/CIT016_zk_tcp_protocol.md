# Transmission Control Protocol (TCP)

**Tags:** #networking #tcp_ip #protocols

## Note
TCP (Transmission Control Protocol) is responsible for managing data transmission between devices. It ensures that the delivery of data between applications is **reliable, ordered, and error-checked**. It operates at the Transport layer of the TCP/IP stack.
