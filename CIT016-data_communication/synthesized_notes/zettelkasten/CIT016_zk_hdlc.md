# HDLC Frames Carry Data and Link Control

**Tags:** #data_communications #hdlc #data_link

## Note
High-Level Data Link Control (HDLC) is a bit-oriented family for point-to-point and multipoint links. Frames use flag `01111110` at their boundaries and fields for address, control, payload, and CRC-based frame check sequence (FCS). Information frames carry user data and may piggyback control; supervisory frames carry control; unnumbered frames support link management. NRM gives a primary control of exchanges; balanced ABM allows either point-to-point peer to initiate.
