# Internet Protocol (IP)

**Tags:** #networking #tcp_ip #protocols

## Note
IP (Internet Protocol) is the core protocol of the internet. It defines and handles how data is transmitted over networks. Specifically, it provides the logical addressing and routing necessary for packets to travel from source to destination using IP addresses. It operates at the Internet/Network layer.
