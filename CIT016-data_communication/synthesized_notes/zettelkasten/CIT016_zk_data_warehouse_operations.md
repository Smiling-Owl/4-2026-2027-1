# Data Warehouse Operations (ETL)

**Tags:** #data_warehouse #etl #data_operations

## Note
Any data warehouse will initially receive random, unstructured, and dirty data. To make this data useful and structured, certain operations are performed sequentially:

1. **Data Cleaning:** Removing inconsistencies and rectifying noisy data containing errors.
2. **Data Refresh:** Broadcasting data from multiple sources and updating it on a timely basis.
3. **Extraction of Data:** Extracting relevant data to make the cleaned data organized for retrieval and mining.
4. **Transformation of data:** Organizing heterogeneous data with native structures into a structure similar to that of the data warehouse.
5. **Data Loading:** Loading the processed data into its respective target repository (databases, data marts, data warehouses).
