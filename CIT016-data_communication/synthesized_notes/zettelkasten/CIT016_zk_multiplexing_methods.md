# Multiplexing Separates Signals by Different Resources

**Tags:** #data_communications #multiplexing #fdm #tdm #wdm #sdm #cdm

## Note
Multiplexing methods differ by the resource used to distinguish signals:

- **FDM - frequency:** Different frequency bands in the same channel.
- **TDM - time:** Different time slots in the same channel.
- **WDM - wavelength:** Different colors of light in the same optical fiber.
- **SDM - space:** Different physical paths, fibers, or wires.
- **CDM - code:** Unique codes over the same frequency channel.

A useful recall rule is: frequency, time, wavelength, space, and code are five different ways to keep shared signals distinguishable.
