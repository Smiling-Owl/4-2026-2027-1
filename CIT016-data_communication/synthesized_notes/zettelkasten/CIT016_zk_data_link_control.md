# Data Link Control Coordinates Reliable Link Transfers

**Tags:** #data_communications #data_link #protocols

## Note
Data Link Control (DLC) coordinates frame exchange over a physical link. Its three concerns in this lesson are line discipline (who sends and when), flow control (how much is sent before waiting), and error control (how damaged or missing frames are handled).
