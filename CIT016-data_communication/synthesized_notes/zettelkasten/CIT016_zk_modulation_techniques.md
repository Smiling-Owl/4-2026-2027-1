# Modulation Techniques

**Tags:** #data_communications #modulation

## Note
Modulation is the process of adding information to a carrier signal (which normally has a constant frequency and amplitude) to convert data into radio waves for transmission. 

- **Analog Modulation** varies a property of the carrier wave in proportion to an analog message signal. It includes:
  - Amplitude Modulation (AM)
  - Frequency Modulation (FM)
  - Phase Modulation (PM)

- **Digital Modulation (Shift Keying)** shifts a property of the carrier signal to represent discrete digital data (bits). It includes:
  - Amplitude-Shift Keying (ASK)
  - Frequency-Shift Keying (FSK)
  - Phase-Shift Keying (PSK)
