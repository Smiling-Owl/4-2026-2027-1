# Data Warehouse Overview

**Tags:** #data_warehouse #data_mining #data_management

## Note
A Data Warehouse is a system used for the storage of information over time by a business or organization. It acts as an archive of historical data, which is periodically added by people in various key departments. This library of data can be retrieved and analyzed for decision-making. 

Businesses primarily warehouse data for **data mining**—looking for patterns of information that will help them improve business processes. It enables cross-departmental data access (e.g., marketing assessing sales team's data).
