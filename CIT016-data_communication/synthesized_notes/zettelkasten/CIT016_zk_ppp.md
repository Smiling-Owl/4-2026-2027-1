# PPP Carries Network Protocols Across Point-to-Point Links

**Tags:** #data_communications #ppp #data_link

## Note
The Point-to-Point Protocol (PPP) encapsulates datagrams from multiple network-layer protocols in frames for a direct link. Link Control Protocol (LCP) negotiates and manages the link; optional authentication may check peers; Network Control Protocols configure particular network layers. PPP framing does not itself encrypt the payload or guarantee retransmission of each frame.
