# Error Correction Can Retransmit or Add Recoverable Redundancy

**Tags:** #data_communications #error_correction #fec #retransmission

## Note
Error correction follows two broad strategies:

- **Backward error correction:** The receiver detects an error and asks the sender to retransmit the data unit.
- **Forward error correction:** The sender includes error-correcting redundancy so the receiver can recover certain errors without retransmission.

Retransmission uses another communication attempt; forward correction spends additional bits to enable local recovery.
