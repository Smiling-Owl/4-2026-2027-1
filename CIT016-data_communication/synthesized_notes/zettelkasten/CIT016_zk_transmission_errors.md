# Transmission Error Types

**Tags:** #data_communications #errors #noise

## Note
An error occurs when received data does not match the data sent. Noise can alter binary bits while they travel through a communication channel.

- A **single-bit error** changes exactly one bit.
- A **multiple-bit error** damages more than one bit.
- A **burst error** flips several consecutive bits.

The error pattern matters because detection and correction methods provide different levels of protection.
