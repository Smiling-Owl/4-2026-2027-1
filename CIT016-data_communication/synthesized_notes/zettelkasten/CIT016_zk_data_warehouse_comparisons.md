# Data Warehouse vs. Database vs. Data Lake vs. Data Mart

**Tags:** #data_warehouse #database #data_lake #data_mart #comparison

## Note
Data Warehouses are often compared to other data storage systems:

- **Database:** A transactional system that updates real-time data to maintain the most recent information. A Data Warehouse, in contrast, aggregates structured data *over time* (historical data).
- **Data Lake:** Holds raw, unrefined data where the specific purpose is not yet determined, mostly used by data scientists. A Data Warehouse holds refined, filtered data for a specific purpose, mostly used by business professionals.
- **Data Mart:** A smaller, subset, and faster version of a data warehouse. It collects data from a small number of sources and focuses on a single subject area or specific department.
