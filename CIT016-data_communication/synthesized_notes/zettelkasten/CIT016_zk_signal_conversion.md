# Signal Conversion (ADC and DAC)

**Tags:** #data_communications #hardware

## Note
Because the physical world is primarily analog and computers operate digitally, converters are required to interface between the two:
- **ADC (Analog-to-Digital Converter):** Encodes a continuous analog signal (e.g., from a sensor or microphone) into a discrete binary code that a digital circuit or computer can process.
- **DAC (Digital-to-Analog Converter):** Translates digital binary values back into continuous voltage levels, recreating an analog signal output (e.g., for a speaker).
