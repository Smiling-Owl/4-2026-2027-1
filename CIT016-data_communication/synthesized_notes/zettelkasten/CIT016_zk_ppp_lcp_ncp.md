# LCP and NCP Configure Different Parts of a PPP Connection

**Tags:** #data_communications #ppp #protocols

## Note
PPP's Link Control Protocol (LCP) establishes, configures, tests, and terminates the data-link connection. Network Control Protocols (NCPs) configure the network-layer protocol carried over that link, such as IPv4 with IPCP or IPv6 with IPv6CP.
